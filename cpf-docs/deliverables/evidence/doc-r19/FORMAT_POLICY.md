# R19 Format Policy

- 사용자 진입 문서: `README.md` 1개만 Markdown으로 유지한다.
- Guide 8종: `.pdf` 정식 열람본 + 같은 basename `.docx` 편집본.
- 설계 산출물 5종: `.pdf` 정식 열람본 + 같은 basename `.docx` 편집본.
- Guide/설계 Authoring `.md` 13개는 Repository에서 제거한다.
- README의 Guide/설계 공식 링크는 PDF만 가리킨다. DOCX는 편집·인계용으로 같은 경로에 제공한다.
- `doc-r15`, `doc-r18` Evidence는 R19로 대체되는 문서 변환 Evidence이므로 exact deletion manifest에 포함한다.
- README가 참조하는 브로셔/Guide Map 이미지는 보호한다.
