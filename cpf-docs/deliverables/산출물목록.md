## 7. 적용

ZIP을 Repository Root에 해제한다. Local 변경이 있는 대상 파일은 먼저 별도 보존하고 경로별 diff를 검토한다. 전체 Working Tree를 초기화하지 않는다.

## 8. Rollback

적용 전 보존한 exact path 파일만 복원한다. `git reset --hard`, `git clean`, `git restore .`를 사용하지 않는다.
