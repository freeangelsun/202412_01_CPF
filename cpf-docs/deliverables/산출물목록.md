활성 정본은 동일 역할 파일을 추가 생성하지 않고 갱신한다. 과거 회차는 Git History로 보존한다. 날짜·QA 번호·FINAL 접미사의 중복 문서를 공식 문서로 추가하지 않는다. 삭제는 exact path Manifest와 Link/Reference Zero 검증 후 수행한다.

## 7. 완료 Gate

산출물이 존재하는 것만으로 완료하지 않는다. Source/API/SQL/Test/Config/Frontend/Script/문서가 양방향으로 연결되고, 해당 Runtime Evidence와 Artifact Hash가 기준 Commit을 가리켜야 한다. 직접 실행하지 않은 검증은 `미검증`으로 남긴다.
