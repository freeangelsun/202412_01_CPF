# CPF Development Harness Canonical Surface Standard

현재 개발/QA 정본은 `cpf-docs/governance/development-harness/` 하나다.

| 역할 | Current Path |
|---|---|
| 실행 정본 | `CPF_DEVELOPMENT_HARNESS.md` |
| 개발 기본지침/Core Policy | `standards/DEVELOPMENT_EXECUTION_CORE_POLICY.md` |
| 제품 Architecture/Requirement | `product/CPF_PRODUCT_ARCHITECTURE_AND_REQUIREMENTS.md` |
| Product Requirement Registry | `current/CANONICAL_PRODUCT_REQUIREMENTS.csv` |
| Closure Inventory | `current/CPF_CANONICAL_DEVELOPMENT_CLOSURE_INVENTORY.csv` |
| Current Status | `current/CURRENT_DEVELOPMENT_STATUS.csv` |
| Role Ledger | `current/ROLE_EXECUTION_LEDGER.csv` |
| Detailed Review | `current/CURRENT_DETAILED_REVIEW.md` |
| Open Issues | `current/OPEN_ISSUES.md` |
| Test/Evidence Index | `current/TEST_AND_EVIDENCE.md` + `evidence/**/current/` |
| Migration/Delete | `CANONICAL_MIGRATION_MAP.csv`, `DELETE_MANIFEST.csv` |
| Harness Evidence | `TEST_AND_EVIDENCE.md`, `PACKAGE_MANIFEST.json`, `SHA256SUMS.txt` |

`cpf-docs/governance/documentation-harness/`는 공식 사용자 문서 생성/검수 정본으로 별도 유지한다. Development Harness와 Documentation Harness는 서로 대체하지 않는다.

- Test 실행 정본: `current/TEST_EXECUTION_LEDGER.csv`

- Garbage/Delete 의사결정 정본: `current/CURRENT_GARBAGE_DECISIONS.csv` + `current/DELETE_MANIFEST.csv`
