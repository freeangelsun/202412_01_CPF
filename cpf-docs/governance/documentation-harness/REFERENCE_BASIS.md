# CPF Documentation Harness Reference Basis

## CPF 우선

이 Harness의 최우선 기준은 사용자 Steering, CPF Target Requirements와 최신 Source다. 외부 문서 작성 관행은 CPF 구조와 사용자 요구에 도움이 되는 부분만 선택적으로 적용한다.

## 선택적으로 반영한 외부 원칙

- Microsoft Word 접근성 지침의 단순한 데이터 Table, Header Row, Merge/Split/Nested Table 지양, Heading Style, Alt Text 원칙
- Google Developer Documentation Style Guide의 Table은 관계형 데이터/비교에 사용하고 단순 목록·긴 설명에는 List/본문을 선호하는 원칙
- WCAG 계열의 대비와 Reflow 취지

외부 기준이 CPF Harness의 좁은 여백, Column 비율, 문서별 Profile, Source 계약과 충돌하면 CPF Harness를 우선한다.
