# Visual Comfort Standard

전체 문서는 정보량을 줄이지 않으면서도 독자가 숨 쉴 수 있는 시각적 리듬을 갖는다.

- Body 10pt, Table body 9pt, Header 9.5pt를 기준으로 하며 더 작은 글자로 페이지를 채우지 않는다.
- 의미가 다른 표·Code·Figure·긴 List 사이에는 전환 여백과 목적 설명을 둔다.
- 7개 이상 긴 Flat List는 의미 그룹으로 나눈다.
- H1/H2 앞 여백은 아래 첫 내용보다 크게 하여 섹션 전환이 보이게 한다.
- 모든 페이지를 실제 Render에서 검수한다.
