> **기준 Repository** `freeangelsun/202412_01_CPF` · **기준 Branch** `master` · **기준 SHA** `1536a0d59004ebade7dcb29383cbe2e758547f8e` (`20260731_03`)  
> **문서 기준일** `2026-07-31` · **Runtime 검증 상태** QA32 전체 Runtime·3DB·Browser·다중 인스턴스 Evidence는 `미검증`  
> **문서 목적** 정확한 Property·환경변수·기본값·소비 Source와 설치·DB·기동·배포·관측·보안·백업·Upgrade·Rollback·장애 복구 Runbook을 제공한다.  
> **주요 독자** 플랫폼 운영자, SRE, 인프라·미들웨어·DB 운영자, 배포·보안 담당자  
> **완료 결과** 운영자가 Source를 다시 탐색하지 않고 환경을 구성·검증·배포·복구하고 exact-SHA Evidence를 남긴다.

> [!IMPORTANT]
> 최신 `master`의 Requirement·Architecture·Source·SQL·Config·Frontend·Test·Script를 교차 확인해 작성한 역할별 정본이다.
> Source에서 확인한 사실과 제품 계약을 구분하며, 실행하지 않은 Build·DB·Kafka·Browser·Failure/Recovery 검증을 성공으로 기록하지 않는다.
> 실제 환경 수행 시 기준 SHA, Profile, 명령, 시작·종료 시각, Exit Code, Expected/Actual, 민감정보 제거 여부를 Evidence에 남긴다.

## 문서 사용 계약

| 상태 | 의미 |
|---|---|
| `완료` | 최신 exact SHA에서 Source·Consumer·Failure/Recovery·필수 Runtime Evidence가 모두 확인됨 |
| `부분 구현` | 일부 계층만 연결되었거나 Legacy/대체 경로가 Primary로 남음 |
| `미구현` | 제품 Source 또는 필수 수직 연결이 없음 |
| `미검증` | Source는 있으나 필요한 실제 환경 검증이 실행되지 않음 |
| `실패` | 필수 Gate·Scenario가 실패함 |
| `재확인 필요` | Source·Evidence·SHA·환경이 상충하거나 불명확함 |

- **Source-confirmed**: 기준 SHA의 Source·Config·SQL·Route·Script에서 직접 확인했다.
- **Product contract**: CPF 정본이 요구하는 동작이다. 실제 Runtime Evidence가 없으면 `미검증`으로 표시한다.
- **Operator procedure**: 운영자가 수행해야 하는 절차다. 화면·권한·환경 차이는 실제 배포 Catalog를 우선한다.
- **Prohibited**: 성공처럼 보여도 제품 안정성·감사·복구를 깨뜨려 금지하는 방식이다.

```text
Requirement → Owner → Public API/SPI → Application/Policy → Adapter/State
→ Runtime Consumer → Security/Approval/Audit → Failure/Recovery
→ Test/Evidence → Guide/EDU → Legacy 제거
```

### 3.3 Property별 운영 절차

#### 3.3.1 `CPF_ARTIFACT_MODE`

| 항목 | 내용 |
|---|---|
| 목적 | CPF Artifact 공급 경로를 단일 모드로 고정 |
| 환경변수 | `CPF_ARTIFACT_MODE` |
| Type | Enum |
| Default | `LOCAL_DEV` |
| 필수 | CI/STG/PROD에서는 명시 권장 |
| 허용·제한 | LOCAL_DEV|REMOTE|OFFLINE |
| 소비 Source | `settings.gradle, build.gradle` |
| 적용 | Build 재실행 |
| 민감정보 | Credential·Password·Secret 원문은 별도 Secret 환경변수/Provider |
| 실패 | Fail-fast 또는 기능 비활성·Readiness 실패; 정확한 Error 확인 |

**설정·변경**

1. 현재 Effective Config와 Version·Hash를 확인한다.
2. 승인된 Change에 Key·Scope·Target Instance를 기록한다.
3. Secret은 Reference만 사용하고 Console·History에 원문을 남기지 않는다.
4. Staging에서 경계값과 잘못된 값을 주입해 Fail-fast를 확인한다.
5. Build 재실행 후 Liveness·Readiness·Functional Probe를 확인한다.
6. 다중 인스턴스면 Instance별 Effective Value와 ACK/NACK를 대조한다.

**검증**

- Property Source가 `settings.gradle, build.gradle`와 일치한다.
- Default가 `LOCAL_DEV`인지 확인한다.
- 제한 `LOCAL_DEV|REMOTE|OFFLINE`를 벗어난 값이 거부되는지 확인한다.
- Config Snapshot에 민감정보가 제거됐는지 확인한다.
- Source SHA·Config Version·적용 시각을 Evidence에 남긴다.

| Default | `빈 목록` |
| 필수 | mTLS 제어 시 필수 |
| 허용·제한 | 승인된 Subject만 |
| 소비 Source | `AgentProperties` |
| 적용 | 재기동 |
| 민감정보 | Credential·Password·Secret 원문은 별도 Secret 환경변수/Provider |
| 실패 | Fail-fast 또는 기능 비활성·Readiness 실패; 정확한 Error 확인 |

**설정·변경**

1. 현재 Effective Config와 Version·Hash를 확인한다.
2. 승인된 Change에 Key·Scope·Target Instance를 기록한다.
3. Secret은 Reference만 사용하고 Console·History에 원문을 남기지 않는다.
4. Staging에서 경계값과 잘못된 값을 주입해 Fail-fast를 확인한다.
5. 재기동 후 Liveness·Readiness·Functional Probe를 확인한다.
6. 다중 인스턴스면 Instance별 Effective Value와 ACK/NACK를 대조한다.

**검증**

- Property Source가 `AgentProperties`와 일치한다.
- Default가 `빈 목록`인지 확인한다.
- 제한 `승인된 Subject만`를 벗어난 값이 거부되는지 확인한다.
- Config Snapshot에 민감정보가 제거됐는지 확인한다.
- Source SHA·Config Version·적용 시각을 Evidence에 남긴다.
