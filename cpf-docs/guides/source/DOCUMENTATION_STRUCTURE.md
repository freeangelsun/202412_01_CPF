# CPF 사용자 산출물 구조

README → 전체 사용 안내 → 기능별 가이드의 선택 Summary → 상세 구현 → Education/Sample/Source 정본 순서로 탐색합니다.

- ADM은 Platform 운영 Control Plane이며 일반 업무 개발 영역이 아닙니다.
- MBW Backoffice는 메뉴·Role·Permission부터 필요한 업무 관리자 기능만 선택합니다.
- Gateway는 선택형 외부 진입점이며 Domain 간 호출의 필수 경로가 아닙니다.
- 공식 DB Vendor는 Oracle/PostgreSQL/MariaDB입니다.
