CPF DEV18 FINAL APPLY / VALIDATE COMMANDS

0) 전제
- 프로젝트 Root에서 실행한다.
- Overlay 파일명: CPF_DEV18_FINAL_OVERLAY_20260819.zip
- Canonical Delete Manifest: cpf-docs/deliverables/DELETE_MANIFEST.csv
- 현재 전달본의 delete candidate는 approved=false이며, 승인되지 않은 항목은 삭제하지 않는다.

1) Overlay 적용 한 줄
$root=(git rev-parse --show-toplevel).Trim(); Set-Location $root; $name='CPF_DEV18_FINAL_OVERLAY_20260819.zip'; $zip=@((Join-Path $HOME "Downloads\$name"),"D:\11096\Downloads\$name") | Where-Object {Test-Path -LiteralPath $_ -PathType Leaf} | Select-Object -First 1; if(!$zip){throw "ZIP missing: $name"}; Expand-Archive -LiteralPath $zip -DestinationPath $root -Force

2) 승인된 Delete Manifest 항목만 안전 삭제 한 줄
$root=(git rev-parse --show-toplevel).Trim(); Set-Location $root; $m=Import-Csv (Join-Path $root 'cpf-docs\deliverables\DELETE_MANIFEST.csv'); $m | Where-Object {$_.approved -eq 'true'} | ForEach-Object {$rel=$_.path.Replace('/','\'); if([IO.Path]::IsPathRooted($rel) -or $rel -match '(^|\\)\.\.(\\|$)'){throw "Unsafe delete path: $rel"}; $p=Join-Path $root $rel; if(Test-Path -LiteralPath $p -PathType Leaf){Remove-Item -LiteralPath $p -Force}elseif(Test-Path -LiteralPath $p -PathType Container){throw "Directory delete is not allowed by file manifest: $rel"}}

3) Java25 로컬 최종 검증 한 줄
$root=(git rev-parse --show-toplevel).Trim(); Set-Location $root; $java=(java -version 2>&1 | Out-String); if($java -notmatch 'version "25'){throw "Java 25 required. Current: $java"}; pwsh -NoProfile -ExecutionPolicy Bypass -File '.\cpf-tools\verification\tools\run-cpf-final-local-validation.ps1' -RepoRoot $root -OutputRoot (Join-Path $HOME 'Downloads')

4) Public Git 생성/검증/Push 한 줄 — 모든 Gate PASS 전에는 Push 단계에 도달하지 않음
$root=(git rev-parse --show-toplevel).Trim(); Set-Location $root; pwsh -NoProfile -ExecutionPolicy Bypass -File '.\cpf-tools\release\public\publish-cpf-public-repository.ps1' -Root $root -Push

5) Git Status 한 줄
git status --short

6) 테스트 가비지 확인 한 줄 — 제품 Source인 cpf-tools/build/**는 삭제 대상이 아님
$root=(git rev-parse --show-toplevel).Trim(); Set-Location $root; Get-ChildItem -LiteralPath $root -Recurse -Force -File | Where-Object {$_.Name -eq '.DS_Store' -or $_.Name -eq 'Thumbs.db' -or $_.Extension -eq '.pyc' -or $_.FullName -match '[\\/]\.pytest_cache[\\/]'} | Select-Object -ExpandProperty FullName

주의
- 2번은 approved=true인 파일만 삭제한다. 현재 false 후보를 자동 승인하지 않는다.
- 3번/4번에서 하나라도 FAIL이면 최종 Runtime/공개 Push 완료가 아니다.
- 사용자 승인 없이 commit/push/delete를 자동 수행하는 별도 우회 명령은 제공하지 않는다.
