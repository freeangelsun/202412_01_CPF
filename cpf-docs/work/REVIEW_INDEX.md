# CPF Current Review Index

## Canonical entry points

- Final target: `cpf-docs/governance/CPF_FINAL_TARGET_REQUIREMENTS.md`
- Current work: `cpf-docs/work/CPF_CURRENT_WORK_REQUEST.md`
- Requirement status: `cpf-docs/work/REQUIREMENT_STATUS.csv`
- Source findings: `cpf-docs/work/CPF_SOURCE_FINDINGS.csv`
- Change manifest: `cpf-docs/work/CHANGE_MANIFEST.csv`
- Delete manifest: `cpf-docs/work/current/DELETE_MANIFEST.txt`
- Test/Evidence: `cpf-docs/work/TEST_AND_EVIDENCE.md`
- Open issues: `cpf-docs/work/OPEN_ISSUES.md`
- Handover: `cpf-docs/work/HANDOVER.md`
- Steering interpretation: `cpf-docs/work/current/STEERING_INTERPRETATION.md`
- Development trace: `cpf-docs/work/current/DEVELOPMENT_REQUIREMENT_TRACE.md`
- Codex revalidation: `cpf-docs/work/current/CODEX_REVALIDATION_REQUEST.md`

세션 번호/날짜가 붙은 동일 목적 결과문서를 current 정본으로 사용하지 않는다.
