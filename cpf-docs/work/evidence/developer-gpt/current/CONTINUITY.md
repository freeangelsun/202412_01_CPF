# CONTINUITY

다음 세션은 이 Overlay가 적용된 **Local Working Tree**를 Source 정본으로 사용한다. Git master/과거 commit으로 전환하지 않는다. Git은 RT-02 local provenance read-only 조회 외 사용하지 않는다. 사용자 승인 없이 fetch/checkout/restore/reset/clean/commit/push 하지 않는다. Runtime 검증 중 새 결함이 나오면 같은 Requirement를 개발GPT 영역에서 다시 열고 Root Cause 전체를 보정한다.
