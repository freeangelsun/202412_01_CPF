1. 역할과 작업 흐름

1.1 ChatGPT 1차 개발

ChatGPT 개발 모델은 다음을 수행한다.

최신 master를 다시 확인한다.

이 QA 문서와 최종 목표 정본을 읽는다.

변경 전에 영향도 분석을 갱신한다.

P0부터 실제 Source·SQL·Migration·Generator·Frontend·Test·문서를 수정한다.

가능한 Build/Test/DB/Browser 검증을 실행한다.

Codex가 검수할 문서를 작성한다.

실행하지 않은 항목을 PASS로 표시하지 않는다.

사용자 승인 없이 Commit/Push/Branch/Tag/Release를 생성하지 않는다.

1.2 Codex 2차 검수·보완

Codex는 ChatGPT 보고를 완료 근거로 사용하지 않는다.

최신 Git Diff와 영향도 Ledger를 대조한다.

변경된 공통 계약의 실제 Consumer 범위를 다시 계산한다.

Build, DB, Runtime, Browser, Multi-instance와 Fault Test를 독립 실행한다.

결함을 발견하면 보고만 하지 않고 직접 수정한다.

동일 검증을 다시 실행한다.

Review, Evidence, Continuity를 최신 SHA로 갱신한다.

사용자 승인 범위에서만 Commit/Push한다.

1.3 완료 흐름
